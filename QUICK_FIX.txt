🔴 PROBLEM: Recipes not displaying when selecting ingredients

✅ QUICK FIX CHECKLIST (Follow in order):

Step 1: Test the API directly
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
File:   test-api.html
Action: Open file → Click "Run Test" → Check if recipes appear
Result: If YES ✓ → API works, problem in app.js
        If NO ✗ → API issue, check key in config.js


Step 2: Verify API key is correct
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
File:   config.js
Line:   12
Current: const SPOONACULAR_API_KEY = "55e3df31e...";
Check:  Should NOT say "YOUR_API_KEY_HERE"
        Should be a 32+ character string starting with: 55e3df31e...


Step 3: Run system diagnostics
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
File:   debug.html
Action: Open file → Click "Run Full Diagnostics"
Check:  All items should be GREEN ✓
        API Key Valid = YES
        DOM Elements Found = > 0


Step 4: Check browser console logs
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
File:   index.html
Action: 1. Open in browser
        2. Press F12 (Developer Tools)
        3. Go to Console tab
        4. Click an ingredient pill
        5. Look for detailed logs showing:
           - "Step 1: Validate inputs" ✓
           - "Step 2: Build API URL" ✓
           - "Step 3: Making fetch request" ✓
           - "Step 4: Response received" ✓ (check status 200)
           - "Step 5: Parsing response JSON" ✓
           - "Step 6: JSON parsed successfully" ✓
           - "Step 7: Calling displayRecipes()" ✓
           - "Step 8: Hiding loading state" ✓

        If stops at certain step → That's the problem!


Step 5: Check Network activity
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
File:   index.html
Action: 1. Press F12 → Network tab
        2. Click an ingredient pill
        3. Look for request to "api.spoonacular.com"
        4. Check response status (should be 200 OK)
        5. Click request → Preview tab
        6. Should show JSON array with recipes

        Red status codes = API error
        No request shown = handleIngredientSelect() not called
